# 任务计量说明

用户明确要求评估用量、费用或人工投入时，仅整理所问指标。复用宿主已提供的数据和原任务记录，遵循[数据安全与记录边界](develop.md#数据安全与记录边界)。缺值注明已有证据覆盖到哪里，不为补数扫描私密会话、要求用户计时或重做需求。

- **来源与归属**　注明来源、适用阶段和覆盖范围。只引用能对应实际运行实例的模型、Agent 和宿主版本。多会话或多个 Agent 分段记录，仅在范围互斥、口径一致且任务归属明确时汇总。累计值相减前核对计数器和起止边界。宿主合计已含子任务时避免重复累计。
- **Token**　按来源保留可得的 Input、Output、Cache Read、Cache Write 和 Total Tokens。只有合计就引用合计。缓存已包含在输入时避免重复相加。上下文窗口大小、多任务会话合计和部分轮次用量均不能证明完整任务用量。
- **费用**　实际金额及币种取自能归属到该任务的账单或结算记录。宿主估算需标明口径，不能用公开单价反推实际账单。
- **重试**　需要分析重试时，按可见证据区分 API 请求重发、Agent 工作单元重跑、工具操作重试及失败后的验证复验。关联的多层重试注明关系，避免重复计数。仅覆盖完整且确认无重试时记为零。
- **人工投入**　区分需求决策、纠错、人工修改与验收。主动分钟只取已有人工计时或可靠记录，排除等待和离开时间。消息数和会话跨度不能代替主动耗时。

对效果的观察复用首次交付和后续反馈。没有同条件基线与完整计量时，只报告已观察到的行为和已覆盖的用量。
